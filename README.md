# Hospital Management System

A console-based Hospital Management System developed in Java using Object-Oriented Programming (OOP) concepts.

## Project Overview

The Hospital Management System is designed to manage basic hospital operations through a simple command-line interface.

The system currently supports patient management, appointment scheduling, and billing operations.

## Features

### Patient Management

- Add new patients
- Automatically generate unique Patient IDs using UUID
- View registered patients
- Search patients using Patient ID

### Appointment Management

- Schedule appointments for patients
- Automatically generate unique Appointment IDs
- Automatically calculate the next available appointment slot
- View scheduled appointments

### Billing Management

- Generate bills for patients
- Automatically generate unique Bill IDs
- Record multiple services
- Store and display total billing amount
- View generated bills

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- UUID
- Java Date and Time API
- Command-Line Interface (CLI)
